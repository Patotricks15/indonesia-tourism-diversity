\section{Feature engineering}
Features are declared in \texttt{conf/features.yaml}. User features
(\texttt{user\_activity\_count}, \texttt{user\_mean\_rating}) are fitted
strictly on the training partition. \texttt{item\_popularity\_rank} is also
training-only. \texttt{item\_category} and \texttt{item\_city} are read
directly from the catalogue and double as the descriptors the content
similarity matrix is built from, so they carry no collaborative-label
signal by construction. A registry check asserts the YAML specification and
the Python implementation agree in both directions.
